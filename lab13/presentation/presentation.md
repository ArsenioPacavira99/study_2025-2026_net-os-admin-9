# Итоги работы

## Вывод

В ходе лабораторной работы была подготовлена расширенная сетевая инфраструктура организации.

Для добавленного оборудования были заданы имена устройств, настроены пароли, локальные учётные записи администратора, доменные имена и удалённый доступ по протоколу **SSH**.

Подготовленная топология может использоваться для дальнейшей настройки VLAN, статической маршрутизации и проверки связности между подсетями.
