# Цель работы

Провести подготовительную работу по первоначальной настройке коммутаторов сети.

# Ход выполнения

В Packet Tracer был создан новый проект лабораторной работы. В логической рабочей области были размещены коммутаторы и оконечные устройства согласно схеме сети **L1**. В проект были добавлены коммутаторы **2950T-24** и **2960-24TT**, персональные компьютеры **PC-PT**, а также серверы **Server-PT**.

Коммутаторы были соединены между собой через соответствующие интерфейсы. К коммутаторам также были подключены рабочие станции и серверы. В результате была построена локальная сеть, включающая узлы площадок **msk-donskaya** и **msk-pavlovskaya**.

![Размещение коммутаторов и оконечных устройств согласно схеме сети L1](Screenshot_1.png){ #fig:001 width=85% }

После построения схемы была выполнена первоначальная настройка коммутаторов. Настройка выполнялась через командную строку устройства в режиме **CLI**. Для каждого коммутатора был задан hostname, настроен управляющий интерфейс **Vlan2**, указан IP-адрес из плана адресации, задан шлюз по умолчанию, настроены пароли для консольного и удалённого доступа, а также включён доступ по **SSH**.

Первым был настроен коммутатор **msk-donskaya-arsenio-sw-1**. Для него был задан IP-адрес **10.128.1.2** с маской подсети **255.255.255.0**. В качестве шлюза по умолчанию был указан адрес **10.128.1.1**. Также были настроены линии **vty 0 4**, консольный доступ, пароль привилегированного режима, локальный пользователь **admin** и доменное имя **donskaya.rudn.edu**. После генерации RSA-ключей был разрешён удалённый доступ по протоколу **SSH**.

# Контрольные вопросы

## 1. При помощи каких команд можно посмотреть конфигурацию сетевого оборудования?

Для просмотра текущей конфигурации сетевого оборудования Cisco используется команда:

**show running-config**

Сокращённый вариант команды:

**show run**

Эта команда показывает текущую активную конфигурацию устройства, которая находится в оперативной памяти **RAM**. В ней отображаются имя устройства, настройки интерфейсов, пароли, параметры удалённого доступа, VLAN, маршруты и другие параметры, которые действуют в данный момент.

Также для просмотра отдельных частей конфигурации могут использоваться дополнительные команды:

**show ip interface brief** — показывает краткую информацию об интерфейсах, их IP-адресах и состоянии;
**show interfaces** — выводит подробную информацию об интерфейсах устройства;
**show vlan brief** — показывает список VLAN и назначенные им порты;
**show version** — отображает сведения об устройстве, версии IOS и времени работы;
**show running-config interface vlan 2** — показывает настройки конкретного интерфейса, например **Vlan2**.

Например, после настройки коммутатора можно выполнить команду:

**show running-config**

и проверить, что на устройстве задано правильное имя, настроен IP-адрес управляющего интерфейса, указан шлюз по умолчанию и включён доступ по SSH.

## 2. При помощи каких команд можно посмотреть стартовый конфигурационный файл оборудования?

Для просмотра стартового конфигурационного файла используется команда:

**show startup-config**

Сокращённый вариант команды:

**show start**

Стартовая конфигурация хранится в энергонезависимой памяти **NVRAM**. Именно она загружается при включении или перезагрузке устройства. Если текущая конфигурация была изменена, но не сохранена, то после перезагрузки эти изменения будут потеряны.

Чтобы текущая конфигурация стала стартовой, используется команда:

**write memory**

или её аналог:

**copy running-config startup-config**

После выполнения этой команды настройки из **running-config** сохраняются в **startup-config**. Затем их можно проверить командой:

**show startup-config**

## 3. При помощи каких команд можно экспортировать конфигурационный файл оборудования?

Экспорт конфигурационного файла выполняется с помощью команды **copy**. Чаще всего конфигурацию экспортируют на TFTP-сервер.

Для экспорта текущей конфигурации используется команда:

**copy running-config tftp:**

После ввода команды устройство запросит IP-адрес TFTP-сервера и имя файла, под которым нужно сохранить конфигурацию.

Пример:

**copy running-config tftp:**

Далее указывается адрес сервера, например:

**10.128.1.100**

Затем задаётся имя файла, например:

**msk-donskaya-arsenio-sw-1-confg**

Также можно экспортировать стартовую конфигурацию командой:

**copy startup-config tftp:**

В этом случае на TFTP-сервер будет отправлен не текущий активный вариант настроек, а сохранённая стартовая конфигурация из **NVRAM**.

Экспорт конфигурации используется для резервного копирования настроек сетевого оборудования. Это позволяет быстро восстановить устройство после сбоя, заменить оборудование или перенести типовую конфигурацию на другой коммутатор.

## 4. При помощи каких команд можно импортировать конфигурационный файл оборудования?

Импорт конфигурационного файла также выполняется с помощью команды **copy**. Если конфигурация хранится на TFTP-сервере, её можно загрузить на устройство.

Для загрузки конфигурации в текущую активную конфигурацию используется команда:

**copy tftp: running-config**

После выполнения команды устройство запросит IP-адрес TFTP-сервера и имя файла конфигурации. Загруженные настройки будут применены к текущей конфигурации устройства.

Также конфигурацию можно загрузить сразу в стартовую конфигурацию:

**copy tftp: startup-config**

В этом случае файл будет записан в **NVRAM** и применится после перезагрузки устройства. После загрузки конфигурации в **startup-config** обычно выполняют команду:

**reload**

чтобы перезапустить устройство и применить импортированные параметры.

Если конфигурация была импортирована в **running-config**, её следует сохранить командой:

**write memory**

или:

**copy running-config startup-config**
